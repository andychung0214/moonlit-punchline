# 月下冷梗旅店美術方向

## 評估過的視覺風格

1. **昭和冷笑研究所**：舊科學雜誌、手帳塗鴉與檢驗章，節奏活潑。
2. **深夜梗便利店**：台日街頭招牌、貼紙與漫畫擬聲字，適合高速闖關。
3. **月下冷泉旅店（採用）**：和紙、冬夜、冷泉與留白，讓「安靜到結冰」成為笑點。

採用第三種方向，是因為它同時容納慢速閱讀與十題挑戰，也能避開常見的霓虹漸層、玻璃卡片和制式插圖。

## 色票

| 名稱 | 色彩 | 用途 |
|---|---|---|
| 和紙 | `#F3F0E8` | 主背景 |
| 墨色 | `#17343B` | 主要文字 |
| 冬夜 | `#102A35` | 深色區塊 |
| 冷泉 | `#557F78` | 主要操作 |
| 月光 | `#E5C36A` | 焦點與分數 |
| 印章 | `#9E4B50` | 答對與警示 |
| 霧氣 | `#DCE7E3` | 次要背景 |

一般文字與背景至少維持 WCAG 2.1 AA 的 4.5:1 對比。

## 字體策略

- 展示文字：`Yu Mincho`、`Hiragino Mincho ProN`、`Noto Serif TC`、系統明體。
- 內文：`Noto Sans TC`、`Yu Gothic`、`Hiragino Sans`、`Microsoft JhengHei`。
- 資料標籤：系統等寬字型。
- 不下載遠端字型，避免隱私、載入與離線問題。

## 元件規格

- **障子門**：首頁兩種模式入口，桌機並排、手機堆疊。
- **房牌**：分類與模式名稱，使用冷泉色及窄字距。
- **湯牌**：分數、連勝、題號，使用等寬數字。
- **印章**：答對、收藏完成；酒紅色、同時附文字。
- **紙張卡片**：1px 墨色半透明邊線、低陰影、最大圓角 12px。
- **月相冷度儀**：唯一的主視覺記憶點，進度與氣氛合一。

## 動畫原則

- 互動回饋 160ms、紙張翻面 320ms、印章落下 420ms。
- 動畫只用於說明狀態，不延遲答案或下一步。
- 答錯降低色溫，不劇烈晃動、不閃爍。
- `prefers-reduced-motion: reduce` 時將非必要動畫縮至 1ms。

## 禁止事項

- 紫藍霓虹漸層、玻璃擬態、發光描邊。
- 無意義 3D 漂浮物、制式 AI 人物與未授權圖片。
- 多處同時持續動畫。
- 只靠顏色傳達答對、答錯或焦點。
- 觸控目標小於 44 × 44 CSS px。
