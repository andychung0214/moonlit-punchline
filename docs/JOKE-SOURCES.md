- 標示「流傳梗重新編題」者：常見語音或字形素材，原作者未確認，不歸屬特定藝人。
- 標示「本次新編」者：本次編寫的題幹、選項與解釋；不宣稱其中每個諧音素材都是首創。

每個擴充題目具有 `source` 欄位，並在既有笑點說明中呈現來源標籤。題目數由資料計算，不再在首頁寫死。
