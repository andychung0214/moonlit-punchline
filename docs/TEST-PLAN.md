# 月下冷梗旅店測試計畫

## 自動測試

- [ ] 題庫共 72 題且六類各 12 題
- [ ] 題目 ID、問題與四個答案選項符合唯一性
- [ ] 每局抽 10 題且不重複
- [ ] 計分、連勝、答錯歸零與結算正確
- [ ] 損壞或不可寫入的本機儲存可安全降級
- [ ] 分享文字與剪貼簿拒絕流程正確
- [ ] 音效不支援與未啟用流程不產生錯誤
- [ ] 必要文件與靜態入口結構完整

## 功能手動測試

- [ ] 從大廳進入挑戰並完成 10 題
- [ ] 題目作答後鎖定選項並揭曉註解
- [ ] 結算顯示分數、答對數與最高連勝
- [ ] 放映室可篩選、翻牌、前後切換與隨機
- [ ] 收藏、取消收藏與只看收藏可用
- [ ] 複製成功與拒絕後手動複製皆可用
- [ ] 音效預設關閉，開啟後可再次關閉
- [ ] 清除紀錄後回到預設狀態

## 行動裝置與 RWD

- [ ] 360px 單欄無水平捲動
- [ ] 768px 雙欄入口與答題卡不溢出
- [ ] 1280px 旅店大廳構圖完整
- [ ] 互動目標至少 44 × 44 CSS px
- [ ] 觸控翻牌、篩選與下一題不需懸停

## 無障礙

- [ ] 只用鍵盤完成兩種模式
- [ ] 焦點順序合理且樣式清楚
- [ ] 作答與複製結果由 ARIA live region 宣告
- [ ] 答對、答錯不只依靠顏色
- [ ] 放大 200% 後內容不被裁切
- [ ] 減少動態效果時無持續霧氣與翻面動畫
- [ ] 螢幕閱讀器可理解題號、選項、答案與收藏狀態
- [ ] 主要文字對比符合 WCAG 2.1 AA

## 靜態部署

- [ ] 根路徑可載入所有相對資源
- [ ] 子目錄路徑可載入所有相對資源
- [ ] `robots.txt` 與 `sitemap.xml` 可存取
- [ ] 開發者工具控制台無錯誤
